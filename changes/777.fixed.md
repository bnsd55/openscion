The server's memory floor is read from one table of the request
shares' live constants - blame, the derive walks, uploads in flight,
reply bytes in flight, file reads, unary replies, the land index, the
gc prune and the stall total - about 6.4 GiB with headroom, with
gauges for the margin, and serve names the host's limit, its source
and the shares at start when the host is under the floor. Before, the
shares were separate constants nothing summed, so a small host could
pass every pool's check and be killed for memory under load (#777).
