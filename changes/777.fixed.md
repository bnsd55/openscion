The server's memory floor is the sum of every request share's live
constant - blame, the derive walks, uploads in flight, reply bytes in
flight, file reads, unary replies, the land index, the gc prune and
the stall total - plus headroom, with gauges for the margin, and serve
names the host's limit, its source and the shares at start when the
host is under the floor. Before, the shares were separate constants
nothing summed, so a small host could pass every pool's check and be
killed for memory under load; docs/operations.md section 1, One
server, carries the floor and its shares (#777).
