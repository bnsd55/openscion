The paged diffs' rename cache keeps its byte total instead of summing
it, and an age order instead of scans: a page's cache work no longer
scales with the number of entries the cache holds. Every entry costs
its map's bytes plus its own overhead (the key twice, the entry, the
shared map's block - derived from `size_of`, the paths' heap bytes
counted per entry), so the cap bounds the entry count too: many paged
diffs stopped at the first page can no longer live outside the cap
until their TTL passes. The `scion_diff_rename_cache_bytes` gauge reads
the same kept total, and now includes the entries' own memory.
