The mount lists a directory with no lock held over the tree fetch:
lookup, readdir, read and readlink fetch first and take the write lock
only to insert, so a slow fetch parks no other call of the mount
(#1387). Two lookups of one cold directory at once both fetch, and the
first insert wins; the loser drops its copy before any file id of its
own has escaped to the kernel, and both calls answer the winner's
handles. The mutations keep their in-lock fetch (their row in the
shortcut table names the rewrite that removes it).
