The mount fetches with no lock held: lookup and readdir fetch a cold
directory's tree and take the write lock only to insert it, and read and
readlink drop the lock before they fetch a file's bytes, so a slow fetch
parks no other call of the mount (#1387). Two lookups of one cold
directory at once both fetch, and the first insert wins; the loser drops
its copy before any file id of its own has escaped to the kernel, and
both calls answer the winner's handles. The mutations keep their in-lock
fetch (their row in the shortcut table names the rewrite that removes
it).
