The server's `--postgres-url` is gone: a URL on the command line is readable by every local account (`ps`), and it carries the database's credentials. A call that still passes it fails at once, before any parsing, with the replacement named - `SCION_POSTGRES_URL` in the environment, or `--postgres-url-file FILE`, the checked read (owner-only, symlink refused) - and never quotes the URL. This completes v0.1.0's deprecation; the scripts and guides moved to the environment or file form.
