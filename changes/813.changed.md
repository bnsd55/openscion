The token flags are gone from every binary's command line: `scn --token`, `scion-cache --token` and `--upstream-token`, `scion-daemon --token` and `--upstream-token`, `scion-server serve --token`, and `scion-server hash-token --token`. A secret on the command line is readable by every local account through `ps`, so a call that still passes one fails at once, before any parsing, and the error names what to use instead - the environment (`SCION_TOKEN`, `SCION_UPSTREAM_TOKEN`) or a checked file (`--token-file`, `--upstream-token-file`) - and never quotes the value. The file and environment forms are unchanged.
